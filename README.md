# Pixel Dino Run

A simple pixelated runner game built with p5.js where a dinosaur tries to escape obstacles.

## How to Run

1.  **Save the files:** Ensure you have the following folder structure:

    ```
    pixel-dino-run/
    |___PROMPT.md
    |___README.md
    |___public
          |___index.html
          |___sketch.js
          |___style.css
    ```

2.  **Open `index.html`:** Navigate to the `pixel-dino-run/public/` directory and open the `index.html` file in your web browser.

3.  **Play the game:**
    * The dinosaur will automatically run.
    * Press the **SPACEBAR** or **UP ARROW** key to make the dinosaur jump over obstacles.
    * The game ends if the dinosaur collides with an obstacle.
    * Press **R** to restart the game after a game over.

## Game Controls

* **Jump:** `SPACEBAR` or `UP ARROW`
* **Restart (after Game Over):** `R`

## Features

* Pixelated dinosaur character.
* Randomly generated pixelated obstacles.
* Scrolling pixelated background.
* Score tracking.
* Game over state and restart functionality.

## Technologies Used

* [p5.js](https://p5js.org/) - A JavaScript library for creative coding.
* HTML5
* CSS3
